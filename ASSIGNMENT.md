# Условие финальной практики Docker Compose

Источник: https://app.simulative.ru/course/34/1708

Нужно написать docker-compose.yml минимум для трех контейнеров: PostgreSQL, Python для взаимодействия с БД и Nginx для веб-сервера с демонстрацией данных. Описать собственные volumes и сеть, связывающую контейнеры. Загрузить образы в публичные репозитории Docker Hub, приложить ссылки на образы и compose-файл. Эта практика проверяется преподавателем.

В реализации: учебный отчет о продажах; данные хранятся в PostgreSQL, API работает на Python, Nginx отдает страницу и проксирует API.
